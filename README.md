# Trazo – Plataforma de arte (prototipo)

Prototipo de una plataforma para artistas independientes. Es una sola página (`index.html`), sin dependencias ni paso de compilación.

## Pantallas
- Inicio: galería, buscador, etiquetas y detalle de obra
- Portafolio de artista (`#artista-luna`, `#artista-marco`, `#artista-ines`)
- Inicio de sesión y registro (simulados)
- Panel del artista: perfil, subir obra, gestionar colección

## Cómo verlo
Abre `index.html` en el navegador.

## Publicarlo
En GitHub: Settings → Pages → Deploy from a branch → `main` / root.
